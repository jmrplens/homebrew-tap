# jmrplens Homebrew Tap

Homebrew formulae for [jmrplens](https://github.com/jmrplens) projects.

## Install

```bash
brew install jmrplens/tap/gitlab-mcp-server
```

## Formulae

| Formula                                                    | Description                                                                                                    |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [`gitlab-mcp-server`](Formula/gitlab-mcp-server.rb)        | [GitLab MCP Server](https://github.com/jmrplens/gitlab-mcp-server) — GitLab REST v4 + GraphQL as MCP tools for AI assistants |

Formulae install the prebuilt, checksum-pinned release binaries and are
updated automatically by each release of the corresponding project.
